## 本日発生した技術的トラブルと対応（次セッションが同じ轍を踏まないために）

1. **J-Quants API の V1 が2026-06-01に廃止されていた**ことに気づかず、旧版スクリプトが常に403で失敗していた。→ V2（APIキー方式、`x-api-key`ヘッダー）に全面書き直し済み
2. **HTTP 200でも中身が空リストのことがある**（`has_real_data()`ヘルパーで対処済み）。ステータスコードだけで成功判定してはいけない
3. **J-Quants APIのレート制限（429）が想定より厳しい**。複数回の調整を経て、現在は**「間隔5秒・429時は10秒待って最大3回リトライ・実行時間30分を許容」**という確実性優先の設定にしている（`scripts/step0_api_probe.py` 冒頭の定数群）。これ以上速くしようとすると結果が虫食いになるという教訓済み
4. **先読み不具合の予防策を横展開済み**: 姉妹プロジェクト trading-app-v2 の EXP-OBS000037（specの窓長定義の算術矛盾がB実装の独自解釈を招いた事例）を調査し、`.claude/agents/chief-strategist.md`・`quant-researcher.md`・`adversarial-reviewer.md` の3体と `portfolio-ledger.md` に恒久ルールとして反映済み。時系列ウィンドウを定義する際は「本数」と「対象範囲」の算術的対応を必ず明記すること
