### 本プロジェクトの賭け

**「暗号資産で枯れたのは『価格由来の方向予測』という族であって、非価格情報そのものではない」**という仮説に賭ける。
日本株は決算・適時開示が制度として時刻付きで配信される点で、暗号資産にない構造を持つ。ここに直交するエッジがあるかを測る。

テクニカル方向予測（既存の4戦略 A〜D）は**1本のスリーブとして在庫に入れるが、主軸として期待しない**。

## EXP-OBS000001（PEAD）spec の確定内容（2026-09-13）

S戦略チーム（A設計兼務）が `research/EXP-OBS000001/00-spec.md` を起票し、**数値基準をロック**した。要点のみ:

| 項目 | 確定内容 |
|---|---|
| 予測変数 | **SUE-P（進捗率サプライズ）= 累計営業利益 `OP` ÷ 直前開示時点の通期会社予想 `FOP_prev` − q/4**。会計値のみ。価格由来の代理変数はゼロ |
| 対象四半期 | 1Q/2Q/3Q のみ（**本決算は除外**。進捗率が1.0に張り付きサプライズが消えるため） |
| エントリー | **D+1（開示日の翌営業日）の寄り**に統一。`DiscTime` で早めない |
| トレール4パラメータ | 初期損切 **−3.0%** ／ 発動水準 **含み益+3.0%（終値ベース）** ／ 追随幅 **終値最高値から−3.0%** ／ **不利方向は日中安値で判定・有利方向は終値のみで更新**（保守側の非対称化） |
| 主ホライズン | **h=5**（D+1寄り→D+5引け）。**日足5本・終値5個・隣接日次リターン4本**の対応を spec §4.1 に明記（EXP-OBS000037 の教訓） |
| 選定/確認 | 選定 2024-06-21〜2025-06-30 ／ 確認 2025-07-01〜2026-06-21。**保有窓が確認期間に食い込む選定イベントは除外** |
| G1 合格 | 確認期間で **IC > 0 かつ 日付ブロック巡回シフト permutation p < 0.05**、かつ上位20%群のグロス平均が正、かつデシル単調性が負でないこと |
| G2 合格 | **Sharpe の有意性に置かない**。①1トレード平均が正 ②累積PnLが正 ③最大DD ≤ 15% ④確認期間の平均が選定期間の50%以上 ⑤生データ12項目の出力に欠落なし |
| G3/G4 | **判定不能**（スリーブ在庫ゼロ）。2本目のスリーブ確定時に再評価する申し送り |

### spec 段階で新たに判明した弱点（prescreen 時点では見えていなかった）

1. **古典的 SUE（過去の予想誤差の標準偏差で正規化）はデータ期間2年では算出不可能**。選定期間の先頭時点で予想誤差の履歴がゼロ期になるため。進捗率ベースの代替定義に切り替えたが、**企業固有の期内季節性を除去できず IC を押し下げる方向に働く**
2. **信用規制（日々公表・増担保）を模擬できない**（規制情報のエンドポイントが取得不可）。**サプライズ大の銘柄ほど規制対象になりやすいため、実運用はバックテスト結果より不利になりうる**
