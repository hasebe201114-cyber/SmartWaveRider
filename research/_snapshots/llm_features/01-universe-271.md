## 選定理由

### 定義

EXP-OBS000001（PEAD）spec `research/EXP-OBS000001/01-spec.md` §5.4 の **U-1〜U-5を通過した銘柄の全集合**。ただしPEADが適用していた **U-6（建玉可能数に基づく上限175銘柄）は適用しない**。

| 項目 | 内容 |
|---|---|
| 基準日 | 2025-07-01（PEAD確認期間の開始日） |
| 銘柄数 | **271銘柄** |
| 規模区分の内訳 | TOPIX Core30: 10銘柄／TOPIX Large70: 39銘柄／TOPIX Mid400: 222銘柄 |
| 適用した条件 | U-1（TOPIX500相当の規模区分）・U-2（制度信用で買建て可能）・U-4（直前60営業日の売買代金中央値≥5億円）・U-5（終値1,000〜3,500円） |
| 適用しない条件 | U-6（建玉可能数上限175銘柄。執行側の制約のため） |
| 凍結ファイル | `research/_snapshots/llm_features/frozen/universe_v1.json`（`codes_sha256 = 07f86898bcbd8fb53b9e0380fff4036138e06256fbd57339e7bdf97550eacd6f`） |
| 再生成方法 | `python3 scripts/llm_features_build_universe.py`（既存キャッシュのみを読む決定的処理。ネットワークに出ない） |

### なぜ175銘柄（PEADの執行可能数）ではなく271銘柄か

175は「同時に何銘柄の建玉を持てるか」という**執行側**の制約（U-6）を適用した後の数。このLLM特徴量トラックは**ポジションを取らない**（データ製造のみ）ため、執行側の上限を継承する理由がない。271に広げないと、175に絞った時点で対象外になった96銘柄の開示は、**あとから遡って取り戻せない**（後述のback-fill禁止のため）ので、将来の選択肢を不可逆に狭めることになる。271への拡張によるコスト増は月額¥250程度に留まる。

### なぜ全市場（全上場銘柄、1営業日あたり約312件）ではないか

コスト算術による。全市場を対象にすると月額US$83（≒¥12,472）となり、これは以前「payできない」と判定したTDnetアドオン（¥11,000/月）とほぼ同額の壁に、別の名前で戻ってしまう。271銘柄のユニバースに絞れば月額US$5.38（≒¥807、資本比0.97%/年）で運用でき、同じ壁を約1/15のコストで回避できる。**ユニバース限定が、このトラックを成立させている条件そのもの。**

### 非対称性についての申し送り

ユニバース外の銘柄の開示テキストは`scripts/snapshot_tdnet_text.py`が無償で保存し続ける（テキストは失われない）。ただし**LLMによる特徴量抽出（ラベル付け）はback-fill禁止のため、後からユニバースを広げても過去分には付けられない**。この非対称性を承知の上で271という数を選んでいる。
