# STEP1: 戦略検討 & 簡易シミュレーション

**実施期間**: 1-2週間  
**ステータス**: 準備段階（未着手）  
**担当**: Claude Code

## 目的

戦略の基本構想を固め、対象銘柄の候補を抽出し、テクニカル指標の有効性を初期検証する。これにより STEP2 のバックテスト項目を明確にする。

## 実施項目

### 1. 対象銘柄スクリーニング

**目標**: 日経225銘柄から 20-30銘柄に絞り込み

**スクリーニング基準**:
- 時価総額: 50B 円以上
- 流動性: 日平均出来高 200万株以上（流動性◎）
- 信用取引対応: Yes
- セクター多様性: 各セクターを均等配置

**出力ファイル**: `research/STEP1-screening.csv`

```csv
銘柄コード,銘柄名,セクター,時価総額,流動性_ランク
9984,トヨタ自動車,輸送機器,29.0T,S
9983,ファーストリテイリング,小売,6.0T,A
8411,みずほフィナンシャルグループ,銀行,7.0T,A
...
```

### 2. テクニカル指標の初期検証

**対象指標** (全9種):
- RSI (Relative Strength Index)
- MACD (Moving Average Convergence Divergence)
- ボリンジャーバンド
- 移動平均クロス（21/75/200日）
- CCI (Commodity Channel Index)
- Stochastic
- ADX (Average Directional Index)
- ATR (Average True Range)
- OBV (On-Balance Volume)

**検証内容**:
各指標について、過去 3-6ヶ月の実績データで：
- 売買シグナルの発火頻度
- シグナルの勝率（簡易測定）
- ダマシの多さ（False Positive 率）

**出力ファイル**: `research/STEP1-technical-validation.xlsx`

表例:
```
指標             | シグナル発火数 | 勝率 (%) | コメント
RSI 30/70       | 45            | 54      | 適度な頻度
MACD GC/DC      | 28            | 51      | やや少ない
BB 反発          | 67            | 52      | ダマシ多い
```

### 3. ニュース影響度の初期推定

**実施方法**:
直近 3-6ヶ月の公開ニュースと株価の相関を手作業で確認

**確認項目**:
- 企業固有ニュース（決算、M&A、人事等）と株価の相関度
- ニュース配信から株価反応までの時間差
- 業界ニュース（セクター影響）の株価への波及

**出力形式**: 簡易スプレッドシート（手作業）

### 4. 期待値試算

**計算項目**:
- 初期資本: 30万円
- レバレッジ: 1.5-2.0倍 → 最大運用可能額: 45-60万円
- 勝率: 55-60%（仮定）
- 平均利幅: 0.8-1.5% / トレード（仮定）

**試算シート**: `research/STEP1-expected-value.xlsx`

例（月間単位）:
```
運用額（1.5倍） : 450,000 円
月間トレード数  : 50 回（1営業日 2.5回）
勝率            : 55%
平均利幅        : 1.0%

期待値          : 450,000 × 55% × 1.0% - 450,000 × 45% × 0.7% 
               = 2,475 - 1,417.5
               = 1,057.5 円 / トレード
月間期待値      : 1,057.5 × 50 = 52,875 円
月間リターン    : 52,875 / 300,000 = 17.6%

（注）実現には多くの条件がある（市場環境、パラメータ最適化等）
```

### 5. ポジション管理・リスク管理の初期設計

**資金配分**:
- 総資本: 30万円
- 実現資本（証拠金）: 20万円
- バッファ（追加証拠金対応）: 7万円
- テスト費用: 3万円

**ポジションサイズ**:
- 1銘柄当たりの最大サイズ: 2万円
- 同時保有銘柄数: 最大 5銘柄
- 最大リスク資本: 各銘柄 2万円 × 5 = 10万円

**リスク管理ルール**:
- 損切: テクニカル反転 or -2% 固定（いずれか先に到達）
- 利確: +1.5% 自動決済 or RSI 反転待ち
- ドローダウン上限: 15%（総資本 4.5万円）
  - 超過時 → 全ポジション強制手仕舞い

### 6. 4つの戦略パターンの仮説構築

| パターン | テクニカルロジック | 保有期間 | 期待勝率 | 特徴 |
|---------|-------------------|---------|---------|------|
| A: モメンタム追従 | MACD + RSI で上昇トレンド追従 | 5-10日 | 55% | トレンド相場で有効 |
| B: 平均回帰 | ボリンジャーバンド逆張り | 2-5日 | 58% | レンジ相場で有効 |
| C: トレンドフォロー | 移動平均クロス + ADX | 10-15日 | 52% | 中期トレンド追従 |
| D: ボラティリティ先行 | ATR 上昇 + Stochastic | 1-3日 | 60% | 短期ボラティリティ利用 |

**検証順序**: A → B → C → D（期待勝率が高い順）
