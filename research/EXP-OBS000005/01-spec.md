### 0.1 ユニバースの年次再確定が先読みを増やさない理由

1. **各確定は確定日より厳密に過去の情報のみを使う。** U-4 の窓は `T[k−60]`〜`T[k−1]`、U-5 は `T[k]` の終値であり、`T[k]` の終値は最速の約定（`T[k]` 以降に開示されたイベントの翌営業日始値）より前に確定している。
2. **確定日の集合は暦（各年の最初の営業日）だけで決まる従属変数であり、選択の自由度が存在しない。**
3. **U-1〜U-7 の手続きは旧 spec と一字一句同一である。** 変わったのは「何回確定するか」だけである。
4. **1回確定のままでは10年化が成立しない。** U-5 の株価帯（1,000〜3,500円）は日本株の株価水準の変化により、6.7年後には別の銘柄群を選ぶ条件になる。1回確定は「2020年初に1,000〜3,500円だった銘柄を2026年まで固定する」ことを意味し、流動性・株価帯フィルタの意図を失う。

## 1. 仮説（1文）

**決算短信の開示によって更新される「会社自身の通期経常利益見通し」の変化量（＝会計サプライズ SUE）は、開示翌営業日始値から起算した5営業日の株価リターンを、日本株 TOPIX500 相当ユニバースにおいて、往復コスト0.35%控除後も正の期待値が残る程度に予測する。**

### 1.1 エッジ族の宣言

- 予測変数の生成過程: **会計データのみ**（会社予想・実績の経常利益と予想売上高）。価格・出来高・ボラティリティを**一切入力にしない**。
- したがって PJ000001 §4 C-3 が低事前確率とした「価格由来の特徴量から方向を予測する」族には属さない。
- ただし出力形（イベント後の一方向継続を取る）は TSMOM と同型である。**この区別が本質的でなかった場合、本 EXP も同じ天井に当たる。この可能性は spec 段階で排除できない。G1 の結果で判定する。**

### 1.2 事前確率の見立て

**中**。ただし根拠は弱い。**本 spec は「日本株 PEAD が文献で確認されている」ことを前提にしない**（一次文献を直接確認できていない。prescreen W-5）。**文献の存在を根拠に基準を緩めることはしない。**

## 3. シグナル定義: SUE（**旧 spec §3 を一字一句そのまま流用する**）

### 3.1 単一の事前登録定義（これ以外を合否判定に使わない）

各イベント（＝ある銘柄 j のある決算短信開示 t）について、以下を定義する。使用フィールドはすべて `/fins/summary`。

| 記号 | 定義 | 取得元フィールド |
|---|---|---|
| `A(t)` | **本開示時点における当期通期経常利益の会社見通し** | 1Q/2Q/3Q 開示 → `FOdP`（当期通期予想）<br>通期（FY）開示 → `OdP`（当期通期**実績**。予想が実績に確定した情報更新として扱う） |
| `B(t)` | **直前開示時点で示されていた「同一会計年度」の通期経常利益の会社予想** | 同一銘柄・同一会計年度に対する通期経常利益予想を含む**直近の開示**（`DiscDate`, `DiscTime` の順で最大）の値。<br>直前が1Q/2Q/3Q開示または業績修正開示 → その開示の `FOdP`<br>直前が前期のFY開示 → その開示の `NxFOdP` |
| `Scale(t)` | **直前開示時点の同一会計年度の通期予想売上高** | 直前が1Q/2Q/3Q開示または修正開示 → `FSales`<br>直前が前期のFY開示 → `NxFSales` |

**RawSUE(j, t) = ( A(t) − B(t) ) / Scale(t)**

### 3.2 会計年度の一致判定（曖昧さを残さない）

- `A(t)` の対象会計年度は本開示の `CurFYSt` / `CurFYEn` で特定する。
- `B(t)` / `Scale(t)` の探索で、直前開示が 1Q/2Q/3Q/修正開示なら `CurFYSt` / `CurFYEn` が本開示のそれと**完全一致**すること。直前が FY開示なら `NxtFYSt` / `NxtFYEn` が本開示の `CurFYSt` / `CurFYEn` と**完全一致**すること。
- 一致する直前開示が存在しない場合、そのイベントは**除外**し、除外件数を記録する。

### 3.3 除外規則（すべて事前登録・件数を必ず記録。**リターンを見る前に適用する**）

1. `A(t)`、`B(t)`、`Scale(t)` のいずれかが null / 空文字 / 非数値 → 除外
2. `Scale(t)` ≤ 0 → 除外
3. 予測対象イベントは **四半期決算短信および通期決算短信の開示のみ**（`DocType` による）。業績修正開示・配当予想修正等は `B(t)` の探索対象にはなるが、**イベント（予測対象）にはしない**
4. `DocType` / `CurPerType` の取りうる値は `research/EXP-OBS000001/10-result/params.json` に2年分の実測がある。**10年分では新しい値が出現しうるため、B実装チームは全ユニーク値と件数を年別に再出力し、本 spec の分類への対応付けを `params.json` に明記すること。対応付けが一意に決まらない場合は推測で埋めず S に差し戻す**（N-6）
5. 同一銘柄・同一 `DiscDate` に同種の開示が複数ある場合（訂正等）、`DiscTime` が最も遅い1件のみを採用する。`DiscTime` が同一なら `DiscNo` が最大の1件

### 3.4 標準化

- **主指標（IC）には追加の標準化を行わない**（Spearman 順位相関は単調変換に不変）。
- **副指標（デシル）には、先読みのないトレーリング分位を使う**:
  - `SUEpct(j,t)` = ユニバース全銘柄の、**`DiscDate` が t より厳密に前**である全イベントの `RawSUE` の経験分布における `RawSUE(j,t)` のパーセンタイル（拡大窓）。
  - 拡大窓の参照イベント数が **200件未満**の場合、そのイベントは**デシル分析からのみ除外**する（IC分析からは除外しない）。除外件数を記録する。
  - 同値（タイ）は平均順位で処理する。**`RawSUE` の厳密なゼロ件数の比率を必ず出力すること。**
  - **【10年化での注意】拡大窓は選定期間の先頭から通算する。** 確認期間の最初のイベントの時点で参照イベント数は既に十分（選定期間3年分）であるため、旧 spec で発生していた「確認期間の序盤でデシル分析が成立しない」問題は起きない。

### 3.5 winsorize / 外れ値処理

## 4. 約定モデルの固定（**旧 spec §4 を一字一句そのまま流用する**）

### 4.0 値幅制限フラグ `UL` / `LL` の解釈と約定可否判定関数

**`research/EXP-OBS000001/01-spec.md` §4.0.1〜§4.0.4 を参照により取り込む。** 要点のみ再掲する（判定は下記2式**以外の方法で行ってはならない**）。

- `UL` / `LL` は**価格水準ではなく 0/1 のフラグ**（文字列 `"1"` / `"0"`）。`UL(t)=1` ⇔ 高値 `H(t)` が制限値幅上限に達した。`LL(t)=1` ⇔ 安値 `L(t)` が制限値幅下限に達した。

```
BUY_BLOCKED(t)  :=  (Vo(t) == 0) or (O(t) is null) or ( UL(t)==1 and O(t) == H(t) )
SELL_BLOCKED(t) :=  (Vo(t) == 0) or (O(t) is null) or ( LL(t)==1 and O(t) == L(t) )
```

- **JPX の制限値幅表を直前終値から自前で再構成して上限/下限価格を計算してはならない。**
- 価格の同値比較は**同一日・同一スケールの値どうし**で行う（生値どうし／調整値どうし。混在禁止）。`Decimal` で厳密比較する。`float` を使う場合の同値判定は `abs(x−y) ≤ 1e-6 × max(1.0, abs(y))`。
- パース規則: `s == "1"` → 真、`s == "0"` / `""` / null → 偽。**それ以外の値が1件でも出現したら推測で埋めずに S へ差し戻す**（§9 の D-7）。

### 4.1 エントリー

- 開示日を `t0`（= `DiscDate`）とする。**エントリーは `t0` の翌営業日 `t1` の始値 `O(t1)`** に固定する。`DiscTime` が場前・場中・場後のいずれであっても同じ扱い（最も保守的な統一）。
- **`BUY_BLOCKED(t1)` が真の場合は約定不能**とし、**そのイベントは見送る（翌日以降の再エントリーを行わない）**。件数を3分類（`Vo=0` / `O` が null / ストップ高寄り付き）で記録する。参考値として `UL(t1)=1` だが `O(t1)<H(t1)` で約定した件数も記録する。
- 約定価格 = `O(t1) × (1 + 0.075%)`（買い片道スリッページ）。

### 4.2 予測単位（G1）の前方リターン

- **ホライズン H = 5営業日（主）**。**R_H(j) = C(t_H) / O(t_1) − 1**（グロス。コスト・スリッページを一切引かない）。
- `t_1`〜`t_H` の営業日が確保できないイベントは G1 から**除外**し、件数を記録する。
- 約定不能イベントも G1 から除外する。**ただし約定不能イベントを除外した場合と、`O(t1)` を用いて仮想的に含めた場合の両方の `IC_bar` を出力する**（主判定は除外版）。
- **価格は調整系列を用いる**（10Y-COMMON §6 H10-5）。生値と調整値を混在させない。

### 4.3 決済ルール（トレーリングストップ）

| # | パラメータ | 固定値 |
|---|---|---|
| 1 | 初期損切幅 | エントリー約定価格の **−3.0%** |
| 2 | トレール発動水準 | 終値ベースの含み益が **+4.0%** 以上に到達した日の**翌営業日から**有効化 |
| 3 | 追随幅 | 発動後、`t_1` 以降の**日次終値**の最高値から **−2.0%** |
| 4 | 更新足と約定価格 | **日足終値のみ**で更新・抵触判定。抵触した日の**翌営業日始値**で約定 |

- 日中高値・日中安値（`H` / `L`）は**トレールの更新にも抵触判定にも使わない**。
- 決済時の約定価格 = `O(t_exit) × (1 − 0.075%)`（売り片道スリッページ）。

### 4.4 決済できない場合（値幅制限の模擬）

- `SELL_BLOCKED(t_exit)` が真なら約定できず持ち越し。**その後の各営業日で同じ式を再評価**し、偽となった最初の営業日の始値で約定する。その間の下落はすべて損失として計上する。
- **最大5営業日**持ち越しても約定できない場合、5営業日目の終値で強制的に評価損益を確定し「強制評価」として件数を記録する。
- 本ルールは、初期損切・トレール抵触・最大保有超過（`t_11` 始値）・§7 D項の手仕舞い・§5.3-10 のサーキットブレーカー清算を含む、**すべての売り約定に一律に適用する**。
- **`UL(t_exit)=1`（ストップ高）は売り約定を妨げない。**

### 4.5 保有期間の上限と、窓長の算術的整合性

**最大保有期間 = 10営業日。** `t_1` から数えて10本目の日足 `t_10` の終値時点で未決済なら、**`t_11` の始値**で強制手仕舞いする。

**窓長・ラグ・オフセットの対応表は 10Y-COMMON §4 が唯一の正本である。** 本 spec は独自の窓を導入しない。**表に無い窓を独自解釈で導入することを禁止する**（N-6）。

### 6.1 G1 主検定

**主指標: 開示日内クロスセクション Spearman 順位相関の等加重平均（`IC_bar`）**

1. 確認期間の各開示日 `d` について、その日にイベントを持つ銘柄群の `RawSUE` と `R_5`（§4.2）の **Spearman 順位相関 `IC_d`** を算出する。タイは平均順位で処理する。
2. **1日あたりのイベント数が5件未満の開示日は `IC_bar` の算出から除外**する（除外日数・除外イベント数を記録）。**残った日数がそのまま `K` であり、DS-2a の計数対象と同一の量である。食い違う場合は S に差し戻す**（N-6）。
3. **`IC_bar` = 対象日の `IC_d` の単純平均**（日を等加重）。
4. **有意性検定 = 開示日ブロック内 permutation**:
   - 帰無仮説: 「同一開示日の銘柄間で、`RawSUE` の順位はリターンの順位を説明しない」
   - 手続き: **同一開示日ブロックの内部でのみ `RawSUE` をシャッフル**し、`IC_bar` を再計算する。これを **10,000回**繰り返す。
   - 乱数シード: **20260915**（固定。変更禁止）
   - 片側 p 値 = ( 1 + #{ `IC_bar_perm` ≥ `IC_bar_obs` } ) / ( 1 + 10,000 )
   - **同日ブロック内でのみ並べ替えることにより、同日発表銘柄が共有するマクロ／セクター共通要因が p 値を過小評価させる問題を構造的に排除する。**

#### 6.1.5 検出力の事前開示と、経済的必要水準との一致（**基準を緩める根拠にも、結果を解釈し直す根拠にも使ってはならない**）

**(a) 統計的な検出下限（MDE）**

- `IC_d` の標準偏差を `SD(IC_d) ≈ 1/√(n_d − 1)` と近似する。
- `SE(IC_bar) = SD(IC_d) / √K`、片側5%の MDE = `1.645 × SE(IC_bar)`。
- 期待値（確認期間の営業日数を約1,635本、旧 spec の実測密度 `K` = 27日/231営業日 で外挿）:

**【第2版】ユニバース 175 → 271 銘柄（D-16）による `n_d` の変化を反映する。** 1開示日あたりのイベント数はユニバース銘柄数に概ね比例するため、`n_d` は **×271/175 = ×1.549** となる。

| 版 | `n_d` の想定 | `SD(IC_d) = 1/√(n_d−1)` | 期待 `K` | **MDE** |
|---|---|---|---|---|
| 第1版（175銘柄） | 7（旧 spec 実測レンジ `[5.0, 9.1]` の下寄り） | 0.408 | 191日 | 0.049 |
| 第1版（175銘柄） | 9（同レンジの上寄り） | 0.354 | 191日 | 0.042 |
| **第2版（271銘柄）** | **10.8**（＝7 × 1.549） | **0.319** | 191日 | **0.038** |
| **第2版（271銘柄）** | **13.9**（＝9 × 1.549） | **0.278** | 191日 | **0.033** |
| （参考）旧 spec（EXP-OBS000001）の実測 | 5.0〜9.1 | 0.354〜0.408 | 27日 | 0.11〜0.13 |

> **上表が置いている仮定と、その不確かさを正直に開示する（`K` を191日に固定していること）**
> ユニバースが1.549倍になると、**`n_d` が増えるだけでなく `K`（1日5件以上の開示日数）も増える**（これまで4件以下だった日が閾値5件を越えるため）。一方で**新たに `K` に加わる日はブロックが小さいため、平均 `n_d` を押し下げる。** 2つの効果は部分的に打ち消し合う。
> **したがって実測 MDE は概ね 0.033〜0.042 の帯に入ると見込むが、`K` と `n_d` の実測値を見るまで確定しない。**
> **この不確かさは合否に影響しない。** DS-2b は**実測の `n_d` と `K`** から `MDE_pre` を計算して 0.055 と比較するゲートであり、期待値がどこに来るかに依存しないためである。

**(b) 経済的に必要な IC 水準（G1-3 から逆算。本 spec で新たに明示する）**

- G1-3 は「確認期間の SUE 上位デシルの `R_5` グロス平均 ≥ +0.35%」を要求する（往復コストと同額）。
- 二変量正規近似の下で、上位デシルの条件付き平均は `E[R | X ∈ 上位10%] = IC × σ_R × E[Z | Z > z_0.9] = IC × σ_R × 1.755` である（`φ(1.2816)/0.1 = 1.755`）。
- したがって **G1-3 を満たすために必要な IC は `IC_econ = 0.35% / (1.755 × σ_R)`**:

| `σ_R`（5営業日の個別株リターンの標準偏差） | **`IC_econ`** |
|---|---|
| 4.0% | **0.0499** |
| 4.5% | **0.0443** |
| 5.0% | **0.0399** |

**(c) 2つの水準がほぼ一致することの帰結（本 spec の設計思想の核心）**

> **【第1版】統計的な検出下限（0.042〜0.049）と、経済的に必要な IC 水準（0.040〜0.050）は、ほぼ同じ帯にあった。**
>
> **【第2版】D-16 により検出下限が 0.033〜0.042 へ下がり、経済的必要水準（0.040〜0.050）の下端以下に収まる見込みとなった。**
>
> **⇒ 本設計が「検出できない」大きさのエッジは、そもそも本PJのコスト構造では取れない**——この帰結は第1版と変わらない。**変わったのは余裕の向きである**: 第1版は両者が一致していた（＝経済的に必要なちょうどの大きさのエッジを検出できるか五分五分だった）のに対し、第2版は**検出下限が経済的必要水準をやや下回る**ため、「経済的に十分なエッジがあれば検出できる」側に倒れる。
>
> **ただし余裕は EXP-OBS000006（検出下限が必要水準の半分以下）ほどではない。** 本EXPは依然として「エッジが無い」と「エッジはあるが小さすぎて取れない」を**明確には分離できない**。この限界は D-16 では解消しない（§6.1.5(d)・§12-2）。
>
> これは偶然ではなく、**DS-2b の閾値 0.055 を「経済的必要水準の上端（0.050）を大きく超えないこと」として設計した結果**である。旧 spec（EXP-OBS000001）の DS-2（≥30日）は検出力と無関係な閾値であり、実測 MDE 0.11〜0.13 という「経済的必要水準の2〜3倍」の状態を検知できなかった。**本 spec はその欠陥を修復している。**
>
> **【第2版で変更しなかったもの】DS-2b の閾値 0.055 は据え置く。** この閾値は `IC_econ` の上端（0.050）から導かれたものであり、**`IC_econ` は D-16 では変化しない**（ユニバース銘柄数に依存しない量である）。**期待 MDE が改善したことを理由に閾値を引き下げることは、導出の根拠を持たない恣意的な変更であり、行わない。** 同様に §6.8.1 の台帳記録文言も、実測値を埋め込む形で書かれているため変更を要さない。

**(d) それでも残る限界（正直に開示する）**

- MDE ≤ 0.055 というゲートは、**IC が 0.050 前後（＝経済的必要水準のちょうど上端）の真のエッジに対して検出力が50%を割る**ことを許容している。
- したがって **G1-1 の不合格は「IC が 0.055 を大きく超える水準のエッジは存在しない」ことの証拠であって、「IC が 0.03 のエッジも存在しない」ことの証拠ではない。**
- **§6.8 に、G1 不合格時の台帳記録文言を事前登録する。結果を見てから表現を選ぶことを禁止する。**
- B実装チームは**実測の `K`・`n_d`・permutation 帰無分布の標準偏差・`R_5` の標準偏差**を出力すること（C品質チームが実測 MDE と `IC_econ` を独立に再計算できるようにするため）。

### 6.3 デシル分析（必須出力）

- `SUEpct` で確認期間のイベントを10デシルに分け、各デシルの `R_5` グロス平均・中央値・件数・標準偏差を出力する。
- **市場超過リターンの定義**: `R_5^excess(j) = R_5(j) − (ユニバース等加重平均 R_5 over 同一窓 `t_1`〜`t_H`)`。
  - **【10年化での変更点なし】** TOPIX 日足は Standard で取得可能になった可能性があるが、**本 spec は市場プロキシをユニバース等加重平均に固定する**（旧 spec と同一。指数の採用は新たな自由度になるため、回す前に固定した定義を変えない）。

## 変更履歴

- **2026-09-15（第2版・凍結）**: **司令塔判断 D-16 の決裁（U-6 の上限 175 → 271 銘柄）を反映した。**
  - **本改訂が K-4（HARKing）に該当しない理由（最重要）**:
    1. **確認期間の前方リターンは、本改訂の時点で S・B・C の誰も1件も観測していない。** B実装チームはまだ起動しておらず、`10-result/` は空である。**すなわち「結果を見てから設計を変えた」という事態が物理的に発生していない。**
    2. **本改訂の手続きは第1版が事前登録していたものである。** 第1版 §10.2 N-12 は「引き上げは司令塔判断 D-16 の管轄であり、**決裁が出た場合に限り、かつ確認期間の前方リターンが未観測であるうちに限り**、S が spec 第2版として改訂する」と明記していた。**本改訂はその条件を両方とも満たしている。** 事前登録された例外を、事前登録されたとおりに行使したものである。
    3. **合否閾値を1つも緩めていない。** `G1-1`〜`G1-6`・`G2-1`〜`G2-6`・`DS-1`〜`DS-7` の閾値は**すべて第1版と同一**である。特に **DS-2b の 0.055 は据え置いた**——この閾値は `IC_econ`（ユニバース銘柄数に依存しない量）から導かれており、期待 MDE が改善したことは閾値を動かす根拠にならないためである。
    4. **むしろ2つのゲートを追加して厳格化した**（`G1-7`・`G2-7`。下記）。**決裁によって基準が緩むことがあってはならない。**
  - **改訂の内容**:
    - **§5.4.1 を新設**し、本 spec の `U6_cap` = **271** を固定した。271 は旧 spec の実測における「U-1〜U-5 を満たす全数」（確定日 2025-07-01・候補511 → U-1/U-2 通過497 → U-5 まで通過271）である。**271 に満たない確定日では全数を採る**（U-7 の下限150は不変）。
    - **期待 MDE を 0.042〜0.049 → 0.033〜0.042 に更新**した（§6.1.5(a)）。`n_d` はユニバース銘柄数に概ね比例するため ×271/175 = ×1.549 となる。**`K` を191日に固定した場合の値であり、実際には `K` も増えて平均 `n_d` を押し下げる**ことを併記した（**実測 MDE は DS-2b が実測の `n_d` と `K` から計算するため、期待値の不確かさは合否に影響しない**）。
    - **§6.1.5(c) を更新**した。検出下限が経済的必要水準（0.040〜0.050）の**下端以下に収まる見込み**となり、「経済的に十分なエッジがあれば検出できる」側に倒れた。**ただし余裕は EXP-OBS000006（検出下限が必要水準の半分以下）ほどではなく、本EXPは依然として「エッジが無い」と「エッジはあるが小さすぎて取れない」を明確には分離できない。**
