## 1. 「方向予測」と「マグニチュード/タイミング検出」を分離する設計思想の妥当性確認

### 1.1 抽象論としては妥当な区別である

「いつ・どれだけ動くイベントが起きるか」（マグニチュード/タイミング）と「どちらに動くか」（方向）は、統計的に異なる推定対象である。**固定ルール（例: 常にロング）は価格特徴量から方向を予測していない**——CLAUDE.mdが低い事前確率を課す族は「価格由来の特徴量から方向を予測する」ものであり、方向を予測せず常に一定の行動をとるルールは定義上この族に属さない。ここまでは妥当な区別であり、本PJが11連敗した「方向予測」という狭い問題設定を、形式的には回避している。

### 1.2 ただし具体化すると、この区別は実質的に機能しない

本PJで実際に利用可能な「マグニチュード/タイミング検出器」は2つしかない（PEAD・ギャップ）。この2つに「固定ルール」を適用すると、必然的に以下のいずれかに帰着する。

**(i) 検出器の符号を読む＝候補C＝変装した方向予測**
「マグニチュードが大きい方向に賭ける」（`SUE>0`なら買い、`z`が深いほど反転を期待して買い）は、検出器の出力の**符号**を使っている。これは方向を予測している。「マグニチュード/タイミング検出器」と呼び名を変えても、入力（価格・会計由来の特徴量）→出力（符号）→行動（買い/売り）という生成過程は、既存のPEAD・ギャップの方向検定（`IC_bar`・デシル単調性）と**完全に同一**である。これは言い換えに過ぎない。

**(ii) 符号を使わない「常にロング」＝候補A・B**
これは形式的には方向予測ではない。しかし、この場合に検証すべき仮説は「イベント検出＋常にロング」という単純な条件付き期待値検定になる。**この検定は、実はPEAD・ギャップのspecに既に組み込まれていた**（下記2・3で詳述）。ギャップについては**既に実測・独立検算済み**であり、答えはすでに出ている（不採用）。PEADについては未検定だが、代わりに必要になるのは「なぜ符号に関係なく常にロングして勝てるのか」という**新しい経済的機序**であり、これは方向予測の事前確率とは別の、独立した新しい仮説である。

### 1.3 結論（設計思想の妥当性）

**分離という設計思想自体は、単なる言い換えではなく、原理的には正しい区別である。** しかし、この区別が「本PJの11連敗を回避する新しい実験」を生み出すかどうかは、**どの固定ルールを、どの検出器に適用するかという具体化に完全に依存する**。具体化した結果、候補Cは言い換えに過ぎず、候補Aは既に答えの出ている問いの再提出であり、候補Bのみが技術的には新しい問いだが、経済的機序を欠く（2・3節で詳述）。**「回避できているのか、それとも問題を言い換えただけなのか」という問いへの回答は、「候補による」であり、本PJで実際に使える2つの検出器に限れば、実質的に新しい非自明な検定を生まない。**

## 2. 「固定ルールの方向決定」の数値的確定と厳密な吟味

### 2.1 候補C（検出器の符号を読む）＝固定ルールではない

候補Cは「最適化しないルール」の体裁を取るが、依然として**価格・会計データから導出した変量（`SUE`または`z`）の符号に賭けの方向を委ねている**。「最適化していない」（閾値を事後に選んでいない）ことと「価格由来の方向予測ではない」ことは別の性質であり、混同できない。**PEADのG1-2（選定期間`IC_bar`符号一致）とギャップのG1-1・G1-4・G1-5（`IC_bar`・`M_bar`の符号、デシル単調性）は、まさに候補Cが賭けている「符号は将来リターンの符号を予測するか」を直接検定したものであり、両方とも不合格（PEADは選定/確認で符号反転、ギャップは確認期間の符号自体が仮説と逆）だった。** 候補Cを再提出することは、既にKillされた仮説を名前だけ変えて再起票することに等しく、**候補Cはこの時点で却下する**。

### 2.2 候補A・B（常にロング）の数値的定義

「常にロング」を厳密に定義すると、検定すべき統計量は次のいずれかになる。

```
候補A（ギャップ）: イベント集合 E_gap = { (code, D) | z(code, D) ≤ z* }（z*は較正済み閾値）
                    に対し、方向を固定して常にロング。
                    検定量 = E[ R_5 | (code, D) ∈ E_gap ]（イベント集合全体の平均リターン）

候補B（PEAD）: イベント集合 E_pead = { (code, D) | 会社予想が開示された（発生の有無のみ）
                    かつ（任意で）|SUE| ≥ 閾値（マグニチュードによる絞り込み。符号は使わない） }
                    に対し、方向を固定して常にロング。
                    検定量 = E[ R_5 | (code, D) ∈ E_pead ]
```

**この定義には、検出器の出力のうち「マグニチュードの大きさ（|SUE|・|z|）」を「イベントを取引対象にするか否かのフィルタ」として使うことは許すが、「マグニチュードの符号」を使うことは許さない**、という一線がある。この一線を越えた瞬間に候補Cへ退化する。

### 2.3 候補A（ギャップ＋常にロング）は既に検定済みであり、新規実験ではない

**これが本節の決定打である。** `research/EXP-OBS000006/01-spec.md` のG1合格条件を再確認すると、G1-3（確認期間イベント集合グロス平均 ≥ +0.45%）・G1-6（選定期間イベント集合グロス平均の符号）は、**`z`の符号（本アイデアの用語では「マグニチュードの符号」）を一切使わず、イベント集合全体（z ≤ z* を満たす候補すべて）に対して常にロングした場合の平均リターン**を測定している。これは**候補Aの検定量と完全に同一の統計量**である。

`research/EXP-OBS000006/20-review.md`（C品質チームの独立検算）が確定させた実測値:

| 期間 | 検定量（イベント集合全体・常にロング） | 結果 |
|---|---|---|
| 選定期間（G1-6） | グロス平均 **-1.16%** | 仮説と逆符号・不合格 |
| 確認期間（G1-3、名目上は合格） | グロス平均 **+0.544%**（閾値+0.45%をわずかに超える） | ただし… |
| 確認期間（G1-7、最大単日を除外） | グロス平均 **-0.13%** | **単一日を除くと不合格に転落** |
| 確認期間（Cの独立集計、上位3日を除外） | グロス平均 **+0.0814%**（1,023件中664件） | 損益分岐+0.45%を大きく下回る |

**「ギャップ検出＋常にロング」という候補Aの賭けは、既に実測され、頑健性を欠くことが独立検算で確定している。** 上位1〜3営業日への依存を除けば経済的に意味のある正のリターンは残らない。これは新しい実験を必要とする未検定の仮説ではなく、**既に答えの出た問いを名前を変えて再提出しているだけ**である。再度回すことは、EXP-OBS000006が既に確定させた結論を知りながら同じデータで同じ検定を繰り返すことになり、意味を持たない。

さらに重要な点として、`gap`の実行モデルは既にトレーリングストップ（PJ000001 C-1決着事項）を採用している。トレーリングストップは損切を早く・利確を長く取るという非対称な決済であり、これは司令塔の提案が想定する「イベント後のボラティリティ拡大を利益に変換する設計（オプション的ペイオフ構造）」に最も近い、**この設計内で実現可能な唯一の非対称ペイオフ機構である**。候補Aはこの非対称機構を**既に内包した状態で**検定され、なお不採用だった。「トレーリングストップによる非対称性を付け加えれば違う結果になるのでは」という反論は、既に反映済みの条件について反論していることになり、成立しない。

### 2.4 候補B（PEAD＋常にロング・符号無視）は未検定だが、経済的機序が構築できない

PEADのG1合格条件（`research/EXP-OBS000005/01-spec.md` §6.2）を確認すると、G1-1（`IC_bar`有意性）・G1-2（選定符号一致）は符号を使う検定であり、G1-3（上位デシルのグロス平均）は「サプライズが最も大きく**正**である」銘柄群に限定した検定であって、これも符号を使っている。**「サプライズの符号を無視し、|SUE|の大小のみでイベントを絞り込み、常にロングする」という候補Bの検定量は、PEADのspecには一度も登場せず、技術的には未検定である。**

しかし、未検定であることは「回す価値がある」ことを意味しない。**この賭けが正の期待値を持つと考えるための、日本市場固有の具体的な機序を構築できるか**を検討する。

候補Bが正の期待値を持つためには、以下のいずれかが成立する必要がある。

| 仮説 | 内容 | 既存結果との関係 |
|---|---|---|
| (a) ドリフト継続説 | 大きなサプライズ（符号問わず）は、その符号方向にリターンが継続する | これは方向予測そのもの（符号に従う）であり、**候補Cに退化する**。かつPEADのG1-2で既に符号不安定（選定/確認で反転）が確認済み |
| (b) 反転説 | 大きなサプライズ（符号問わず）は過剰反応であり、その後リターンは逆方向に戻る | これは**候補Aと同一の構造**（ギャップの賭け＝過剰な動きの反転）であり、既にギャップで検定・不採用済み |
| (c) announcement effect（符号非依存の一般的アナウンスメント・プレミアム） | 決算発表という「大きな不確実性が解消されるイベント」自体が、符号と無関係に平均して正のリターンをもたらす（例: 不確実性解消後のリスクプレミアム縮小、注目度上昇による需要増） | **日本市場固有の制度的機序が提示できない。** 一般的な「不確実性解消」効果は世界共通の仮説であり、CLAUDE.mdが要求する「なぜ日本株では結論が変わりうるか」の具体的な制度的根拠（単元株・値幅制限・TDnet適時開示・信用規制等）を一つも動員できない |
| (d) 非対称救済説 | 悪いサプライズの下落は日本固有の需給構造（自社株買い・機関投資家の底値買い支え等）で緩和される一方、良いサプライズの上昇は緩和されない、という非対称性がある | **完全に未実証の仮説であり、本PJのいかなるデータでも検証されていない。これを根拠に据えることは、S自身がEXP-OBS000009の却下時に禁じた「評価する側が正当化を代わりに作文する行為」に該当する** |

**(a)は候補Cへの退化、(b)は候補Aと同一構造（既にKill済み）、(c)は日本固有の機序が無い、(d)は未実証の作文——4つの経路をすべて塞がれる。** さらに、本PJの執行層はオプションを一切利用しない（kabu STATION APIによる現物・信用の株式取引のみ）ため、司令塔提案の「オプション的ペイオフ構造」という比喩は**線形のロングオンリー株式ポジションでは実現できない**。トレーリングストップによる非対称化（2.3節）は既にギャップ・PEAD双方の実行モデルに組み込まれており、候補Bで新たに追加できる非対称性は無い。

**結論: 候補Bは技術的に未検定の統計量だが、それが正の期待値を持つと考えるための日本市場固有の具体的機序を、S戦略チームは構築できなかった。** これはCLAUDE.mdの必須原則（「なぜ日本株では結論が変わりうるのかを具体的に明示する」）を満たさず、EXP-OBS000009の却下基準（司令塔テーマに市場固有の具体的メカニズムが示されていない場合、Sが代わりに正当化を作文することはHARKingと紙一重）と同じ基準で不成立と判定する。

## 3. PEAD・ギャップの既存資産の再利用可能性の具体的な洗い出し

**重要な区別（依頼内容の混同禁止事項）**: PEAD・ギャップのKill判定は「方向予測」の合否判定（G1のIC・デシルスプレッド等）に対するものであり、**イベント検出そのものの精度（データ十分性ゲートDS-1〜DS-7・C7-1〜C7-3が全項目合格していること）は独立に確立された事実であり、Killによって否定されていない**。以下、両者を区別して整理する。

### 3.1 再利用可能（Killされていない・確立済みの資産）

| 資産 | 出典 | 内容 | 再利用可否 |
|---|---|---|---|
| 参照営業日カレンダー`T`・選定/確認分割規則`m=floor(N/2)` | 両EXP §A-1/A-2 | 契約データ全期間からの機械的な分割 | ✅ そのまま再利用可 |
| 候補ユニバース構成（U-1〜U-7） | 両EXP §5.4（共通） | TOPIX500相当・信用買建可・流動性5億円・株価帯1,000〜3,500円・上限175/下限150 | ✅ そのまま再利用可 |
| データ十分性ゲート（DS-1〜DS-4/DS-1〜DS-7・C7-1〜C7-3） | 両EXP §A-4/A-5 | 全項目合格が確定済み（PEAD 7/7・ギャップ9/9） | ✅ **イベント検出の精度そのものは確立済み資産。これはKillの対象外** |
| PEAD: `RawSUE`計算・イベント抽出（除外規則5件） | `research/EXP-OBS000005/01-spec.md` §3.1〜3.3 | 会社予想の変化量を会計データのみから構成 | ✅ イベントの発生タイミング・マグニチュードの計算式として再利用可 |
| ギャップ: `σ_gap`/`z`計算・配当落ち/分割併合識別（V-1〜V-6検証済み） | `research/EXP-OBS000006/01-spec.md` §3.1〜3.2 | ストレスイベントの検出・identifcationロジック | ✅ イベントのタイミング・マグニチュードの計算式として再利用可 |
| 実行モデル（`BUY_BLOCKED`/`SELL_BLOCKED`・トレーリングストップ4パラメータ） | 両EXP §4.0〜4.5 | 値幅制限・決済モデルの日本株固有模擬 | ✅ 方向を問わず再利用可（ロング側はそのまま、ショート側は候補では使わない） |
| PEADとギャップの事象排反性検査（§9-7、重複0件確認済み） | 両EXPのreview | 2つの検出器が同じイベントを別々に数えていないことの保証 | ✅ 将来複数検出器を併用する場合の前提として再利用可 |

### 3.2 再利用不可（方向予測に固有・Killの直接対象）

| 資産 | 内容 | 再利用不可の理由 |
|---|---|---|
| PEAD G1-1・G1-2・G1-4・G1-5 | `IC_bar`・符号一致・市場超過・デシル単調性 | 符号を使う検定であり、候補B（符号無視）には適用できない。かつG1-2は既にKillの直接原因 |
| ギャップ G1-1・G1-4・G1-5 | `IC_bar`・`M_bar`・デシル単調性 | 同上。ギャップの符号予測仮説そのものがKillされている |
| ギャップ G1-3・G1-6・G1-7 | イベント集合全体のグロス平均（常にロング） | **これは方向予測ではなく候補Aの検定そのものであり、既に実測・Kill済み**（2.3節）。再利用ではなく「既に結果が出ている」という位置づけになる |

**まとめ**: イベント検出の**土台（3.1節）は健全な資産であり、再利用に何の問題もない**。しかし、「固定ルール＋常にロング」という賭けそのもの（候補A・B）を評価するための**新しい成功基準**をこの土台の上に構築する必要があり、そのうちギャップ版（候補A）は既存specの中に既に存在していて答えが出ている。PEAD版（候補B）は存在せず新設が必要だが、2.4節の理由でその新設に値する機序が無い。

## 5. 却下を覆す条件

以下をすべて満たす場合に限り、候補Bの再検討をS戦略チームに要請できる。

1. **日本市場固有の具体的機序**が、2.4節(a)〜(d)のいずれにも該当しない形で提示されること（単に「不確実性解消」等の市場共通の一般論では不可。単元株・値幅制限・TDnet適時開示・信用規制・板寄せ単一オークションのいずれかに直接結びつく制度的根拠を要する）
2. その機序が、**既にKillされた候補A（ギャップの反転仮説）・候補C（符号継続仮説）のいずれとも異なる、第3の経路**であることが論証されること
3. 成功基準（上記4節）を回す前に数値で凍結すること
4. B実装チームが着手する前に、G1相当の予測単位検定に加えてG2パイプライン統合の両方を測定する設計であることを明記すること

**候補Aは覆らない。** これは機序の問題ではなく、既に実測・独立検算済みの結果であるため、同一データ・同一定義での再検討は行わない。ホライズン・閾値・ユニバースを変える場合は、それ自体が新しい事前登録を要する別のEXPであり、「失敗した設計を直そうとして基準を選び直す」ことはHARKing（K-4）に該当する。

## GO/却下の理由（まとめ）

1. **「方向予測とマグニチュード/タイミング検出の分離」という設計思想は、抽象論としては妥当だが、本PJで実際に使える2つの検出器（PEAD・ギャップ）に対して具体化すると、実質的に新しい検定を生まない**（候補C=言い換え、候補A=既に答えが出ている再提出）。
2. **候補A（ギャップ＋常にロング）は新規実験ではない。** `EXP-OBS000006`のG1-3/G1-6/G1-7が既にこの正確な統計量を測定・独立検算済みであり、単一/上位イベント日への依存を除去すると経済的に意味のあるリターンは残らない（-0.13%〜+0.08%、いずれも損益分岐+0.45%に届かない）。
3. **候補B（PEAD＋常にロング・符号無視）は技術的に未検定だが、正の期待値を支持する日本市場固有の具体的機序が構築できない。** 検討した4つの経路（継続・反転・アナウンスメント効果・非対称救済）は、それぞれ候補Cへの退化・候補Aへの退化・日本固有性の欠如・未実証の作文のいずれかに帰着する。オプション的ペイオフによる正当化は、本PJの執行層がオプションを利用しないため実現不可能であり、トレーリングストップによる非対称化は既にギャップの失敗した検定に組み込まれている。
4. **候補C（検出器の符号を方向として使う）は固定ルールではなく、変装した価格由来方向予測である。** PEAD・ギャップ双方で個別に既にKillされている族と生成過程が同一であり、CLAUDE.mdの必須原則により低い事前確率のまま扱う。
5. **イベント検出そのもの（データ十分性ゲート・候補ユニバース・実行モデル）は健全な資産として確立されており、Killされていない。** 将来、候補B以外の新しい固定ルール、または新しい検出器（EXP-OBS000010のEDINET大量保有報告書等）が提示された場合、この資産は引き続き再利用可能である。

**次のspec確定には進まない。** `research/portfolio-ledger.md`への追記対象として整理する。
