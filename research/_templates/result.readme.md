# 生結果（Result）の置き方 - 10-result/

> 担当: 実装チーム（quant-researcher）
> 鉄則: **生データのみ。解釈・採否は書かない**（C品質チームが独立に再判定するため）。

このフォルダ `10-result/` に以下を保存する：

| ファイル | 内容 |
|---|---|
| `prediction-unit.json` | 予測単位の結果。非重複サンプル、permutation p値、有効n を含む |
| `pipeline.json` | パイプライン統合の結果。Sharpe / 最大DD / 期間別・レジーム別・**単元離散化後の実効ポジションサイズ** |
| `params.json` | 使用した全パラメータ（バージョン管理） |
| `cost-model.json` | 適用したコスト前提（実測値/仮置きの別を明記） |
| `run.log` | 実行ログ。**再現用の実行コマンドを必ず含める** |

## ルール

- 数字の良し悪しのコメントを書かない
- spec が要求した測定を**両方（予測単位＋パイプライン）**揃える
- 決定的であること（同じコマンドで同じ結果）
- 日本株固有の模擬条件（単元離散化・値幅制限・決算跨ぎ回避）の適用状況を `params.json` に記録する
- 実行: `python scripts/xxx.py`
